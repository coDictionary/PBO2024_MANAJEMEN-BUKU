# Tugas Proyek Pemrograman Berbasis Objek 2024  
**Aplikasi Manajemen Buku Perpustakaan**  

## Deskripsi Proyek  
Proyek ini merupakan implementasi dari konsep Pemrograman Berbasis Objek (PBO) yang bertujuan untuk membangun sebuah aplikasi manajemen buku perpustakaan. Aplikasi ini memungkinkan pengguna untuk mengelola data buku, seperti menambahkan, menampilkan, mengedit, menghapus, dan mencari buku berdasarkan ID buku.  

## Fitur Utama  
- **Tambah Buku**: Memasukkan data buku baru ke dalam sistem.  
- **Tampilkan Stok Buku**: Melihat daftar semua buku yang tersedia beserta jumlah stok.  
- **Edit Buku**: Mengubah informasi buku yang sudah ada.  
- **Hapus Buku**: Menghapus data buku dari sistem.  
- **Cari Buku**: Menemukan buku berdasarkan ID buku.  

## Konsep OOP yang Diterapkan  
1. **Enkapsulasi**: Melindungi data dengan membuat properti bersifat private dan menyediakan akses melalui metode getter dan setter.  
2. **Inheritance**: Menggunakan pewarisan class untuk memanfaatkan kembali kode dan memperluas fungsionalitas.  
3. **Abstract Class**: Menggunakan class abstrak untuk mendefinisikan kerangka umum yang harus diimplementasikan oleh subclass.  
4. **Exception Handling**: Menangani error secara elegan menggunakan mekanisme try-catch untuk menjaga stabilitas program.  

## Teknologi yang Digunakan  
- **Java**: Bahasa pemrograman utama untuk pengembangan aplikasi.  
- **JSON**: Format penyimpanan data untuk menyimpan informasi buku secara lokal.  
- **GUI Swing**: Membuat antarmuka pengguna (UI) berbasis desktop.
